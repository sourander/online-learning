# 2C: Skriptaus

Kuten huomaatte Azure-palvelun pystyttäminen jopa Terraform scripteillä vaatii hieman käsityötä. Eli jos/kun manuaalinen työ alkaa ärsyttää, voi bonushaasteena luoda skriptit "scripts/run_all" ja "scripts/destroy_all", joilla palvelun käynnistys ja sammutus helpottuvat. 

Bonushaaste vaikuttaa `Koodi`-kriteerin arviointiin positiivisesti.
